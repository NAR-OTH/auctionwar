# 🏆 حرب المزادات - Auction War Bot

بوت تليجرام للعب الجماعي الحماسي داخل الكروبات!

---

## 🚀 الميزات

- ✅ **دعم كروبات متعددة** — كل كروب له بياناته المستقلة
- ✅ **نظام تيمات كامل** — إنشاء، انضمام، قيادة
- ✅ **مزادات تلقائية** — كل 10 دقائق بأزرار تفاعلية
- ✅ **نظام الهجوم** — هاجم التيمات واسرق خزائنها
- ✅ **أزرار Inline** — كل التفاعلات بأزرار سريعة
- ✅ **نظام القائد** — انتخابات ديمقراطية + أوامر حصرية
- ✅ **نقاط الشرف** — منافسة مستمرة على الصدارة
- ✅ **تأثيرات الأيتمات** — دروع، مضاعفات، قدرات خاصة

## ⚙️ الإعداد

### 1. المتطلبات
```bash
pip install -r requirements.txt
```

### 2. إعداد المتغيرات
```bash
export BOT_TOKEN="توكن_البوت_من_BotFather"
```

### 3. التشغيل
```bash
python main.py
```

## 📖 أوامر اللعبة

### أوامر عامة
| الأمر | الوصف |
|-------|-------|
| `/start` | بدء اللعبة |
| `/help` | قائمة الأوامر |
| `/join` | انضم للعبة / اختر تيم |
| `/status` | حالتك الحالية |

### أوامر اللاعب
| الأمر | الوصف |
|-------|-------|
| `/work` | اعمل واكسب الذهب (كل 5 دقائق) |
| `/attack` | هاجم تيماً آخر (كل 10 دقائق) |

### أوامر التيمات
| الأمر | الوصف |
|-------|-------|
| `/createteam اسم` | أنشئ تيم جديد |
| `/myteam` | معلومات تيمك |
| `/leaderboard` | ترتيب التيمات |

### أوامر القائد فقط
| الأمر | الوصف |
|-------|-------|
| `/lockattack` | قفل/فتح الهجوم |
| `/lockjoin` | قفل/فتح الانضمام |
| `/distribute مبلغ` | وزّع ذهب على الأعضاء |
| `/kick` | ردّ على عضو لطرده |
| `/stopgame` | إيقاف اللعبة |

## 🏆 منطق اللعبة

### الذهب والخزينة
- كل لاعب يملك ذهباً شخصياً
- 30% من كل عمل يذهب لخزينة التيم
- الخزينة تُستخدم في المزادات والهجمات

### المزادات
- تبدأ تلقائياً كل 10 دقائق
- مدة كل مزاد 3 دقائق
- المزايدة بأزرار سريعة (10، 50، 100، 250 ذهب)
- الفائز يحصل على الأيتم تلقائياً

### الهجوم
- يسرق 15% من خزينة الضحية
- كولداون 10 دقائق بين الهجمات
- يمكن حمايته بـ "درع الحصن"

### القيادة
- القائد الأول هو منشئ التيم
- يمكن التصويت لتغيير القائد (51% من الأعضاء)
- القائد له صلاحيات إضافية

## 📝 ملاحظات تقنية

- كل البيانات مربوطة بـ `group_id` لدعم كروبات متعددة
- SQLite مع WAL mode لأداء أفضل
- الأزرار الإضافية محمية بـ `user_id` لمنع التلاعب
- الكولداون محسوب بالـ timestamp لمنع السبام
